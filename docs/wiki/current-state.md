# Current state

This repository serves one standalone Fumadocs documentation site for
TileTactician at `docs.tiletactician.com`. The canonical authoring surface is
the flat MDX tree under `tiletactician/`; `content/docs/` is derived output and
is regenerated by `node _migration/tools/run-migration.mjs` (deterministic,
with an unmapped-icon gate that fails generation).

The site brand is TileTactician's own: amber `#F59E0B` signal on a near-black
void (`#0A0A0F`, matching the app's dark-first UI), the tile mark in
`public/logo.svg` / `public/favicon.svg`, and no Axiom identity anywhere in
the chrome. The product index doubles as the landing page; `next.config.mjs`
rewrites `/` and the clean page URLs (`/getting-started`, `/board-entry`,
`/board-scanning`, `/rack-analysis`, `/endgame`, `/tile-bag`,
`/share-extension`, `/faq`, `/changelog`) onto the `tiletactician/*` canonical
routes so the address bar stays product-prefix-free.

Deep pages render source-tree-derived related-guide wayfinding
(`lib/page-context.ts`), product-identity accents, evidence-backed
`ProductPreview`/`ProcessFlow` visuals, and a fail-closed Mermaid fallback.
Contract tests assert navigation parity, non-empty metadata, and per-product
navigability (`npm run test:links`), and the canonical link checker validates
routes, fragments, and assets before build (`npm run links:check`).

Content truth boundary: the live product (CrossPlayer Pro at
`smynkr/Crossplay-Pro`) and the previous docs site (the pre-rebuild
`docs.tiletactician.com`) are authoritative for product behavior; the docs
site is the public surface. The app is in active development — pricing and
availability are announced at launch.
