## Where to start

The public browser solver is available at
[tiletactician.com/solver](https://tiletactician.com/solver/). It accepts a
board screenshot or manual entry and lets you review the board before solving.
This is separate from the native mobile app.

The app repository is an Expo / React Native project. Its README documents
this local development setup:

```
git clone https://github.com/smynkr/Crossplay-Pro.git
cd Crossplay-Pro
npm install
npx expo start
```

These commands launch a development build; they are not consumer installation
instructions. The App Store URL referenced by the product repository returned
404 on 2026-10-09, so a current iOS install listing is not verified here.

## Your first analysis

1. Open TileTactician.

2. Tap **Manual Entry** to open the board editor, or **Scan Board** to import a
photo of your game.

3. Place tiles on the grid to match the current game state — see
[Board entry](/tiletactician/board-entry) for tips.

4. Enter your rack tiles in the rack bar at the bottom.

5. Tap **Analyze Board**.

The mobile solver searches locally and shows results after the search
completes; it does not stream partial placements. The solver returns at most
100 unique placements, ordered by score and then word, so this is a capped
result set rather than a complete list of every legal play.

## What the results show

Each result row displays:

- **Word** — the primary word formed

- **Score** — total points including premium squares

- **Position** — grid coordinates and direction (across / down)

- **Cross-words** — any secondary words formed perpendicular to the play

Results can be sorted by **Score**, **Length**, or **A–Z**. Sorting applies to
the returned set of up to 100 placements. Tap any row to preview it on the board.
