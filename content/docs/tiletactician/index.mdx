import { CircleHelp, Flag, Grid2x2, History, Rocket, ScanLine, Share2, ShoppingBag, Trophy } from 'lucide-react';

TileTactician (CrossPlayer Pro) provides native Scrabble and NYT Crossplay board
analysis with a bundled word list. The mobile solver searches locally and
returns up to 100 highest-scoring unique placements after the search finishes;
it does not stream partial results. The exact edition and provenance of the
mobile word-list asset are not identified in the repository.

The browser-based solver is a separate public surface at
[tiletactician.com/solver](https://tiletactician.com/solver/). Board scanning
uses an authenticated, credit-gated server service; it is not the offline
solver.
